# Machine Learning para Predicción de Precios Inmobiliarios en Perú

## Descripción

Proyecto desarrollado para el curso de Sistemas Inteligentes y Machine Learning de la Universidad Privada del Norte.

El objetivo fue desarrollar modelos predictivos capaces de estimar el valor de venta de inmuebles en Perú utilizando características físicas de las propiedades y variables macroeconómicas.

## Tecnologías Utilizadas

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib
* Seaborn
* Google Colab

## Algoritmos Implementados

* Regresión Lineal
* Árbol de Decisión
* K-Nearest Neighbors (KNN)

## Dataset

Se utilizaron datos inmobiliarios históricos complementados con variables macroeconómicas como:

* Tipo de Cambio
* IPC
* Año
* Distrito
* Área
* Habitaciones
* Baños
* Antigüedad

## Resultados

El modelo K-Nearest Neighbors obtuvo el mejor rendimiento alcanzando un coeficiente R² aproximado de 0.79 para la predicción de precios inmobiliarios.
